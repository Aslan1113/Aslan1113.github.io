## ✨ 这个站能干什么

- 📚 **真题题库**：按题型分好类，想练哪块练哪块
- ✅ **逐题解析**：给参考答案，也逐条讲每个选项为什么对、为什么错
- 🤖 **AI 答疑**：看不懂就问，AI 顺着这道题讲（不想用可以在设置里关掉）
- ⏱ **限时作答**：按测评的节奏做完，立刻判对错、算正确率
- 📕 **错题本**：做错的题自动收进来，之后专门重做
- ⭐ **收藏夹**：觉得好的题收藏起来，随时回看
- 📈 **学习统计**：自动记学习时长（新题 / 错题分开算），还有日历热力图
- 🧩 **自定义题库**：把自己的题从截图 / Word / PDF 导进来刷
- 🎨 **按你的习惯来**：浅色 / 深色主题、字号、每轮做几题、界面语言都能调
- 🔁 **云端同步**：登录后进度、错题、收藏能跨设备同步
- 🔗 **游客数据自动合并**：不注册也能刷；哪天注册登录了，本机进度会自动并到账号里，换手机接着做
- 📱 **手机端优化过**：首页题型双列排布、一屏看全，裁题能缩放、能双指捏合

## 🚀 30 秒上手

1. 打开 👉 **<https://aslan1113.github.io/>**
2. 首页挑一个题型（比如「言语理解与表达」「数量关系」），点进去就能开始
3. 选答案，马上出对错，点「查看解析」看逐项讲解
4. 做错的题会自动进「错题本」，之后可以专门重做
5. 想换主题、改字号、调每轮题量、开关 AI 解析，去「设置」页
6. 手机、平板、电脑都能用；不登录时进度存在本机浏览器里

> 不注册也能刷。注册登录后，进度、收藏、错题会同步到云端，换设备也能接着做。

## 🛠 它是怎么搭出来的

- 前端：React 18 + Vite，打包成纯静态页面
- 后端：Supabase（登录 / 数据库 / AI 函数）
- 转发：Cloudflare Pages Function，用来绕过后端的域名白名单
- 托管：GitHub Pages，纯静态，不用服务器

<details>
<summary>🧑‍💻 想照着搭一个 / 自己部署（给爱折腾的你）</summary>

仓库里是已经打包好的静态文件，不用装 Node 也能跑：

- 本地：随便起个静态服务器打开根目录就行（比如 `python -m http.server`）。
- 部署到 GitHub Pages：
  1. 仓库名用 `<你的用户名>.github.io`，站点发布在根目录，绝对路径才正常
  2. **Settings → Pages → Build and deployment → Source** 选 **Deploy from a branch**
  3. 分支选 `main`、目录选 `/ (root)`，保存，等 1～2 分钟

关于登录 / 云同步：原后端的 Supabase 挂在 Meoo 域名下，网关只认原站域名，换域名后登录会 CORS / 403。解决办法是加一个很小的转发代理（[proxy-worker.js](proxy-worker.js)，已部署为 Cloudflare Pages Function），把请求转过去，并把 `Origin` 伪装成白名单域名；站点里写死的后端地址也换成了这个代理。
</details>
